# A. Translation

## Problem Statement

Given two strings `s` and `t`, determine whether `t` is the reverse of `s`.

---

## Approach

The solution reverses the first string and compares it with the second string.

---

## Algorithm

1. Read the strings `s` and `t`.
2. Reverse string `s`.
3. Compare the reversed string with `t`.
4. Print "YES" if they are equal; otherwise, print "NO".

---

## Complexity Analysis

- Time Complexity: O(n)
- Space Complexity: O(1)

---

## Concepts Used

- Strings
- String Reversal
- C++ STL
- Character Comparison
