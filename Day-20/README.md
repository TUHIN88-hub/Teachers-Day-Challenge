# Day 20 - Teacher's Day Coding Challenge

## Overview

Day 20 of the Teacher's Day Coding Challenge focused on strengthening concepts related to **Strings, Mathematics, Optimization, and Vector Simulation**.

The problems solved today involved checking reversed strings, minimizing resources using mathematical calculations, and determining equilibrium through vector addition.

---

## Problems Solved

### Problem 1: Translation
- **Platform:** Codeforces
- **Difficulty:** Easy

#### Concepts Covered:
- Strings
- String Reversal
- Character Comparison
- C++ STL

#### Approach:
The given string was reversed and compared with the translated string. If both strings were identical, the translation was considered correct; otherwise, it was incorrect.

**Time Complexity:** O(n)  
**Space Complexity:** O(1)

---

### Problem 2: Park Lighting
- **Platform:** Codeforces
- **Difficulty:** Easy

#### Concepts Covered:
- Mathematics
- Optimization
- Ceiling Division
- Arithmetic Operations

#### Approach:
Each lantern can illuminate at most two squares. Therefore, the minimum number of lanterns required is the ceiling value of half the total number of squares. This is calculated efficiently using the formula:

`(n × m + 1) / 2`

**Time Complexity:** O(1) per test case  
**Space Complexity:** O(1)

---

### Problem 3: Young Physicist
- **Platform:** Codeforces
- **Difficulty:** Easy

#### Concepts Covered:
- Vectors
- Mathematics
- Simulation
- Coordinate Systems

#### Approach:
The x, y, and z components of all force vectors were summed separately. If the resultant force along all three axes became zero, the body was in equilibrium; otherwise, it was not.

**Time Complexity:** O(n)  
**Space Complexity:** O(1)
