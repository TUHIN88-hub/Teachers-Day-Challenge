Problem: A. Petya and Strings

Platform: Codeforces

Problem Statement

Compare two strings lexicographically without considering character case.

Approach
Convert both strings to lowercase.
Compare the resulting strings.
Print:
-1 if first string < second string
1 if first string > second string
0 otherwise
Complexity Analysis
Time Complexity: O(n)
Space Complexity: O(1)
Concepts Used
Strings
Lexicographical Comparison
Character Manipulation
