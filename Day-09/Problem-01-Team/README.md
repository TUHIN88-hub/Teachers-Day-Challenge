Problem: A. Team

Platform: Codeforces

Problem Statement

Three friends will attempt a problem only if at least two of them are sure about its solution.

Given their opinions for each problem, determine how many problems they will solve.

Approach
Read n.
For each problem:
Read p, v, t.
If p + v + t >= 2, increment answer.
Print the final count.
Complexity Analysis
Time Complexity: O(n)
Space Complexity: O(1)
Concepts Used
Implementation
Counting
Conditional Statements
