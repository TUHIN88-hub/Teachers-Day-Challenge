# 59A - Word

## Problem Statement

Given a word consisting of uppercase and lowercase Latin letters:

- If the number of uppercase letters is greater than the number of lowercase letters, convert the entire word to uppercase.
- Otherwise, convert the entire word to lowercase.

## Approach

1. Count uppercase and lowercase characters.
2. Compare the counts.
3. Convert the entire string accordingly.
4. Print the resulting word.

## Complexity Analysis

- Time Complexity: O(n)
- Space Complexity: O(1)

## Concepts Used

- Strings
- Character Manipulation
- Counting
- Implementation
