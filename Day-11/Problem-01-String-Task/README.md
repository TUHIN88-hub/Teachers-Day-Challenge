# 118A - String Task

## Problem Statement
Given a string consisting of uppercase and lowercase Latin letters:

1. Remove all vowels (A, O, Y, E, U, I).
2. Convert all remaining letters to lowercase.
3. Insert a '.' before each consonant.

Print the resulting string.

## Approach

- Convert each character to lowercase.
- Check whether it is a vowel.
- If it is not a vowel, append '.' followed by the character.

## Complexity

- Time Complexity: O(n)
- Space Complexity: O(n)

## Concepts Used

- String Manipulation
- Character Processing
- Lowercase Conversion
