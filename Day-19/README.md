# Problems Solved

## Problem 1: A. Domino Piling
**Platform:** Codeforces  
**Difficulty:** Easy  

### Key Concepts:
- Mathematics
- Greedy Thinking
- Arithmetic Operations
- Optimization

### Approach:
A domino covers exactly two squares. The total number of squares on the board was calculated using `M × N`, and dividing it by 2 gave the maximum number of dominoes that could be placed without overlapping.

### Complexity Analysis:
- **Time Complexity:** O(1)
- **Space Complexity:** O(1)

## Problem 2: A. Night at the Museum
**Platform:** Codeforces  
**Difficulty:** Easy  

### Key Concepts:
- Strings
- Greedy Algorithm
- Circular Distance Calculation
- Character Manipulation

### Approach:
The pointer initially starts at `'a'`. For every character in the given word, the minimum rotation distance was calculated by checking both clockwise and counterclockwise movements around the circular alphabet. The minimum distance was added to the answer.

### Complexity Analysis:
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

---

## Problem 3: A. Soft Drinking
**Platform:** Codeforces  
**Difficulty:** Easy  

### Key Concepts:
- Mathematics
- Implementation
- Integer Division
- Resource Optimization

### Approach:
The number of possible toasts from the drink, lime slices, and salt was calculated separately. The minimum among these three values determined the total possible toasts, which was then divided equally among all friends.

### Complexity Analysis:
- **Time Complexity:** O(1)
- **Space Complexity:** O(1)
