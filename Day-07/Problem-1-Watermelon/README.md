# Watermelon

## Problem

Determine whether a watermelon of weight `w` can be divided into two positive even-weight parts.

## Approach

* Check if `w` is even.
* Ensure `w > 2`.
* If both conditions are satisfied, print `YES`; otherwise print `NO`.

## Time Complexity

O(1)

## Space Complexity

O(1)

## Concepts Used

* Mathematics
* Conditional Statements
* Edge Case Handling
