# Day 15 - Teacher's Day Challenge

## Problems Solved

### Problem 1: Reverse Integer (LeetCode 7)
- Reversed the digits of a signed 32-bit integer.
- Handled overflow cases by returning 0 when the reversed integer exceeds the 32-bit signed integer range.

**Concepts Used:**
- Mathematics
- Modulo & Division
- Integer Overflow Handling

**Language Used:** Java

---

### Problem 2: Is your horseshoe on the other hoof? (Codeforces)
- Determined the minimum number of horseshoes required to make all four horseshoes have different colors.
- Used a set to count distinct colors and calculated the required replacements.

**Concepts Used:**
- STL Set
- Unique Element Counting
- Basic Mathematics

**Language Used:** C++

---

### Problem 3: Boy or Girl (Codeforces)
- Determined the gender based on the number of distinct characters in the username.
- Used a set to store unique characters and applied odd-even logic to determine the result.

**Concepts Used:**
- Strings
- STL Set
- Unique Character Counting

**Language Used:** C++

---
