# 281A - Word Capitalization

## Problem Statement

Given a word, capitalize its first letter while keeping the remaining letters unchanged.

## Approach

1. Read the input string.
2. Convert the first character to uppercase using a built-in function.
3. Print the modified string.

## Complexity Analysis

- Time Complexity: O(1)
- Space Complexity: O(1)

## Concepts Used

- Strings
- Character Manipulation
- ASCII / Character Functions
