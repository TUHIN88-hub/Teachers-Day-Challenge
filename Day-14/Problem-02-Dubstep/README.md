# A. Dubstep

## Problem Statement

Given a dubstep remix where the string "WUB" is inserted between, before, or after words, restore the original song by separating the words with a single space.

## Approach

1. Traverse the given string.
2. Detect occurrences of "WUB".
3. Replace consecutive "WUB" sequences with a single space.
4. Print the recovered original song.

## Complexity Analysis

- Time Complexity: O(n)
- Space Complexity: O(1)

## Concepts Used

- Strings
- String Traversal
- Pattern Matching
