# A. Presents

## Problem Statement

Given an array where the i-th friend gives a gift to friend p[i], determine for every friend who gave them a gift.

## Approach

1. Create a new array to store the answer.
2. Traverse the given array.
3. For each friend i who gives a gift to p[i], store i at the position p[i].
4. Print the resulting arrangement.

## Complexity Analysis

- Time Complexity: O(n)
- Space Complexity: O(n)

## Concepts Used

- Arrays
- Index Mapping
- Simulation
- Implementation
