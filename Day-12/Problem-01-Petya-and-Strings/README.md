# Petya and Strings

## Problem Statement

Given two strings consisting of uppercase and lowercase Latin letters, compare them lexicographically without considering letter case.

## Approach

1. Convert both strings to lowercase.
2. Compare them lexicographically.
3. Output:
   - -1 if first string is smaller
   - 1 if first string is greater
   - 0 if both are equal

## Complexity Analysis

- Time Complexity: O(n)
- Space Complexity: O(1)

## Concepts Used

- Strings
- Character Manipulation
- Lexicographical Comparison
