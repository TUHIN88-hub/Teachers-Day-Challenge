# Problem 01 - Football

## Problem Link
https://codeforces.com/problemset/problem/96/A

## Difficulty
800

## Language
C++

## Concepts Used
- Strings
- Linear Traversal
- Simulation

## Approach

- Traverse the string from left to right.
- Count consecutive identical characters.
- Reset the count whenever the character changes.
- If the count reaches 7, print "YES".
- Otherwise, print "NO" after completing the traversal.

## Time Complexity

O(n)

## Space Complexity

O(1)
