## ✅ Problem 1: Queue at the School

### Problem Link

Codeforces - Queue at the School

### Approach

Simulated the queue transformation for `t` seconds. During each second, whenever a boy (`B`) stands immediately before a girl (`G`), they swap positions. Careful index handling ensures that a child moves at most once per second.

### Key Concepts

* Simulation
* String Manipulation
* Greedy Swapping

### Complexity

* Time: O(n × t)
* Space: O(1)

### Learning Outcome

Learned how to model time-based transformations and perform controlled swaps efficiently.

Codeforces - Kefa and First Steps

## ✅ Problem 3: Valera and Plates

### Problem Link

Codeforces - Valera and Plates

### Approach

Used a greedy strategy to preserve bowls whenever possible because Type-1 dishes can only use bowls. Plates were consumed strategically for Type-2 dishes to minimize future washing operations.

### Key Concepts

* Greedy Algorithm
* Resource Management
* Simulation

### Complexity

* Time: O(n)
* Space: O(1)

### Learning Outcome

Learned how local optimal choices help achieve a globally optimal solution in resource allocation problems.
