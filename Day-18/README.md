# Problems Solved

## Problem 1: A. Bit++
**Platform:** Codeforces  
**Difficulty:** Easy  

### Key Concepts:
- Strings
- Simulation
- Conditional Statements
- Basic C++ Programming

### Approach:
The variable `x` was initialized to 0. For each statement, the middle character of the string was checked:
- If it was `'+'`, the value of `x` was incremented.
- If it was `'-'`, the value of `x` was decremented.

After processing all statements, the final value of `x` was printed.

### Complexity Analysis:
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

## Problem 2: A. Arrival of the General
**Platform:** Codeforces  
**Difficulty:** Easy  

### Key Concepts:
- Arrays
- Greedy Approach
- Index Manipulation
- Simulation

### Approach:
The first occurrence of the tallest soldier and the last occurrence of the shortest soldier were found. The number of swaps required to move the tallest soldier to the front and the shortest soldier to the end was calculated. If their movements overlapped, one move was reduced.

### Complexity Analysis:
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

---

## Problem 3: A. Word Capitalization
**Platform:** Codeforces  
**Difficulty:** Easy  

### Key Concepts:
- Strings
- ASCII Manipulation
- Character Conversion
- Conditional Logic

### Approach:
The first character of the word was checked. If it was a lowercase letter, it was converted into uppercase while keeping the remaining characters unchanged.

### Complexity Analysis:
- **Time Complexity:** O(1)
- **Space Complexity:** O(1)
