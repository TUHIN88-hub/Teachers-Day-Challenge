# A. Word Capitalization

## Problem Statement

Given a word consisting of uppercase and lowercase English letters, capitalize the first character of the word while leaving all other characters unchanged.

---

## Approach

Read the input string and check its first character.

- If the first character is lowercase, convert it into uppercase.
- Keep all the remaining characters unchanged.

The conversion is performed using ASCII value manipulation.

---

## Algorithm

1. Read the input string.
2. Check whether the first character is lowercase.
3. If it is lowercase, convert it into uppercase.
4. Print the modified string.

---

## Complexity Analysis

- Time Complexity: O(1)
- Space Complexity: O(1)

---

## Concepts Used

- Strings
- Character Manipulation
- ASCII Conversion
- Conditional Statements
