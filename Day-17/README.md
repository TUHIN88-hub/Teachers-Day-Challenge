Problem 1: A. Stones on the Table

Platform: Codeforces
Difficulty: Easy

Key Concepts:
Strings
Greedy Observation
Character Comparison
Iteration
Approach:

Traversed the string of stone colors and compared each stone with its previous one. Whenever two neighboring stones had the same color, one stone needed to be removed. The total count of such occurrences gave the minimum number of removals.

Complexity Analysis:
Time Complexity: O(n)
Space Complexity: O(1)
Problem 2: A. Sereja and Dima

Platform: Codeforces
Difficulty: Easy

Key Concepts:
Arrays
Greedy Algorithm
Two Pointer Technique
Simulation
Approach:

Used two pointers at the beginning and end of the card sequence. During each turn, the player selected the card with the larger value. The chosen value was added to the respective player's score, and turns alternated until all cards were taken.

Complexity Analysis:
Time Complexity: O(n)
Space Complexity: O(n)
Problem 3: A. Cheap Travel

Platform: Codeforces
Difficulty: Easy

Key Concepts:
Greedy Approach
Mathematical Optimization
Cost Minimization
Approach:

Considered all possible ticket purchasing strategies:

Buying only single-ride tickets.
Buying special tickets for complete groups and selecting the cheaper option for remaining rides.
Buying only special tickets even if some rides remained unused.

The minimum cost among all possibilities was the answer.

Complexity Analysis:
Time Complexity: O(1)
Space Complexity: O(1)
