# Football

## Problem Statement

Given a string consisting of characters '0' and '1', determine whether there are at least seven consecutive equal characters.

## Approach

1. Traverse the string.
2. Count consecutive equal characters.
3. If the count reaches 7, print YES.
4. Otherwise, print NO.

## Complexity Analysis

- Time Complexity: O(n)
- Space Complexity: O(1)

## Concepts Used

- Strings
- Counting Consecutive Elements
- Greedy Traversal
