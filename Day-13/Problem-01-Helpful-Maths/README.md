# Helpful Maths

## Problem Statement

Given a sum consisting only of numbers 1, 2, and 3 separated by '+', rearrange the numbers so they appear in non-decreasing order.

## Approach

1. Extract all digits from the string.
2. Store them in a vector.
3. Sort the vector.
4. Print the sorted digits separated by '+'.

## Complexity Analysis

- Time Complexity: O(n log n)
- Space Complexity: O(n)

## Concepts Used

- Strings
- Sorting
- STL
- Greedy Observation
