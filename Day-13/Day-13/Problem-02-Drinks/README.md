# Drinks

## Problem Statement

Given n drinks where the i-th drink contains p_i percent orange juice, determine the percentage of orange juice in the mixture formed by taking equal amounts from each drink.

## Approach

1. Read all percentages.
2. Calculate their sum.
3. Divide the sum by n.
4. Print the result with sufficient precision.

## Complexity Analysis

- Time Complexity: O(n)
- Space Complexity: O(1)

## Concepts Used

- Mathematics
- Average Calculation
- Floating Point Arithmetic
