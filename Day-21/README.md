---

## Problems Solved

### Problem 1: Twins
- **Platform:** Codeforces
- **Difficulty:** Easy

#### Concepts Covered:
- Greedy Algorithm
- Sorting
- Arrays

#### Approach:
The coin values were sorted in descending order. The largest coins were selected one by one until the sum of selected coins became strictly greater than the sum of the remaining coins.

**Time Complexity:** O(n log n)  
**Space Complexity:** O(n)

---

### Problem 2: Even Odds
- **Platform:** Codeforces
- **Difficulty:** Easy

#### Concepts Covered:
- Mathematics
- Number Theory
- Pattern Observation

#### Approach:
Instead of generating the entire sequence, the number of odd values was calculated first. Based on the position k, the answer was directly computed from either the odd or even section.

**Time Complexity:** O(1)  
**Space Complexity:** O(1)

---

### Problem 3: Bit++
- **Platform:** Codeforces
- **Difficulty:** Easy

#### Concepts Covered:
- Simulation
- String Processing
- Conditional Statements

#### Approach:
The variable x starts from 0. Each statement either increments or decrements x based on whether it contains "++" or "--".

**Time Complexity:** O(n)  
**Space Complexity:** O(1)
